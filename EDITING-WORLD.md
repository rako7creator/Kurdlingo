# Editing the world in Godot

Open main.tscn. Expand SoraniWorld > EditableWorld in the Scene panel.
The world is now visible before Play. Word objects are named Word_apple,
Word_chair, and so on. Use the Scene filter to find a word, select its top-level
Word_ node, and press F with the mouse over the 3D view to frame it.
Use W to move, E to rotate, R to scale, or Inspector > Transform for exact values.
Save main.tscn with Ctrl+S, then F5 to test. Saved transform changes are applied
by the game's world builder. Personal saved object positions can override word
positions; use the game's Reset moved objects setting when testing those words.

This first editor bridge supports transforms of existing nodes. Adding/deleting
objects or editing mesh/material properties requires changes to the world builder.
Move the top-level object so its collision and graphics move together.
Teacher and podcast actors are still generated separately at runtime.

The preview is generated by tools/generate_editor_world.gd. Do not regenerate it
after editing without backing up main.tscn and scenes/editable_world.tscn.
The transform bridge uses deterministic traversal indices; if the builder's node
structure changes, regenerate the preview and reapply/review layout changes.
